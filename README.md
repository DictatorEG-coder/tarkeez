# تركيز (Tarkeez)

تطبيق أندرويد يحظر التطبيقات والمواقع التي تختارها أثناء جلسات التركيز، ويعمل بالكامل على الهاتف دون إنترنت ودون جمع أي بيانات.

## المزايا
- **جلسة تركيز:** اختر نوع التركيز (قائمة تطبيقاتك أو الكل) ثم المدة (15 / 30 / 60 / 120 دقيقة أو مدة مخصصة).
- **القوائم:** قوائم حظر بأيام وأوقات محددة، مع قوالب جاهزة.
- **الوضع الصارم:** قفل الإعدادات لمدة محددة.
- **إشعار انتهاء الحظر** عند نهاية الجلسة.
- **تقرير يومي** في آخر اليوم: وقت استخدام الهاتف، وأكثر التطبيقات استخدامًا، وتركيزك اليوم.
- **السجل:** كل جلسات التركيز والوقت الذي أنجزته.
- **حظر المحتوى:** يوتيوب شورتس ويوتيوب ميوزك.

## الأذونات
خدمة إمكانية الوصول (للحظر)، الوصول إلى بيانات الاستخدام (للإحصاءات والتقرير)، الإشعارات، والتنبيهات الدقيقة.
